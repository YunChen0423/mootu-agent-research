# MooTu 评测协议 v1.0

目标：验证输入证据是否支持当下判断、是否应介入、是否选择合适策略/目标，以及具身反馈是否给真实讨论带来收益。把工程正确性、决策质量和小组效果分开报告，不汇总成单一“智能分”。

方法依据：NIST AI RMF 的 [Measure](https://airc.nist.gov/airmf-resources/airmf/5-sec-core/) 强调记录测试方法、基准和不确定性；[ACUTE-EVAL](https://arxiv.org/abs/1909.03087) 提供多轮对话的成对人工比较方法。以下指标、样本规划和阈值是本项目提出的研究协议，不能当作这些来源替本项目验证过。

## A. 工程约束与回归

运行 `npm run check && npm test && npm run eval`。硬门槛：语法/契约/因果可见性检查全过；未来信息读取、无效成员目标、非法策略、冷却违规、凭空投票均应为 0。任何违规都阻止进入参与者实验。

活动测试包含追加未来、未完成发言、改名、往回拖动、成员沉默、缺票、重复票、平票和完整模拟模型工具链。模拟 provider 的通过只说明协议执行正常。合成输入只检查工程和初步行为，不代表真实主持效果。

## B. 离线决策评测

**输入单位**是一个完整会话，包括预先已知的成员名单、时间戳事件流和预先固定的检查时刻。**评分单位**是检查点。系统只读取该时刻已结束的发言和历史决策，不接触后续标签或未来方案。没有显式截止时间时禁止利用最终片长判断阶段。现有 JSONL 的 acceptableStrategies 是作者初始标签，可以允许多个合理策略，不要求逐字文案。

数据先按完整小组/会话划分训练、开发、测试（建议 60/20/20），同一会话、改名变体或主题复述必须在同一分区。预试 10–15 个会话用于完善标注手册；主测试数量根据预试的组内相关和目标效应做功效分析后预注册，不把 12 个合成输入当作足够的研究样本。应覆盖自然活跃、短暂停顿、长期失衡、重复发散、明确收敛、冲突/拒绝邀请、低识别质量及不同人数。新增真实数据需获得参与者授权。

每点至少 2 位标注者独立看相同历史前缀，不看系统名、输出和未来片段。先标 should_intervene、允许策略集合、合法目标集合、阶段、证据 event_id 与不确定性；再冻结标签。分歧报告原始一致率和 Cohen's kappa（类别），独立标注完成后由第三人裁决；多标注者/缺失评分使用合适的 alpha 并注明类型，不隐瞒裁决前分歧。

|指标|计算与分母|解释|
|---|---|---|
|策略可接受率|预测属于允许策略集合的点数 / 已评分点数|同时报告每种策略样本量和召回，避免 observe 占比掩盖问题|
|是否介入 P/R/F1|非 observe 为正类；TP/FP/FN/TN|允许集合同时包含 observe 与介入的点不纳入该二分类分母|
|误介入率|FP / 所有标注为无需介入的点|反映打断成本，不用总体准确率替代|
|目标命中率|正确策略且正确目标 / 所有必须邀请的标注点|把漏邀请算错；多合法目标需扩展为集合匹配|
|阶段准确率|阶段正确点数 / 有阶段标签的点数|发散/收敛分别报告，不以切换次数作为成功|
|证据支持率|逐条可由历史事件支持的事实主张 / 全部事实主张|人工标注，提供 event_id；不以“有文字解释”代替支持|
|候选方案保真度|有来源、无虚构、去重且覆盖标注方向的候选比例|人工评估；语言相似度不等于语义正确|
|工具执行率|完整合法工具链的窗口 / 全部请求窗口|失败和降级必须保留，不只评分成功样本|
|延迟/成本|每个决策窗口端到端 p50/p95、token/费用、失败率|当前 runner 仅保存整会话延迟，逐窗成本仍需 provider usage 埋点|

比较条件：①始终观察；②冻结规则基线；③模型+同一 Harness；④消融条件（无记忆/无效果复盘）作为后续独立实验。相同输入、成员名单和时间点，禁止把规则回退当模型成功。真实模型每会话至少 3 次独立运行，记录模型标识、日期、provider 设置、失败率和全部原始工具输出；报告运行间方差。

以会话为聚类单位进行 paired bootstrap（建议 10,000 次），报告指标差与 95% CI；不能将同一会话的连续窗口当独立样本。分主题、人数和输入质量报告子组结果。现有合成回归报告不提供总体泛化 CI，不作显著性结论。

## C. 输出质量盲评

给标注者同一历史前缀及匿名 A/B 输出，顺序随机并平衡。对相关性、介入时机、事实依据、低压力程度、可行动性分别 1–5 分；允许“无法判断”。记录成对偏好与理由。

统一锚点：1=明显不合适/无证据/造成压力；3=基本相关但泛化、时机或信息不足；5=贴合已知上下文、有证据、尊重自主性、下一步明确。事实依据 1=捏造关键内容，3=大部分有据但混有未证实推断，5=所有事实可追溯。不得用模型自己的 benefit/confidence 当人工质量标签。

`annotation-template.csv` 是初始独立标注表，评分为空；评分列必须由真实标注者填写。研究者不能用系统输出直接反推金标准。

## D. 真实小组与具身效果

离线回放只能判断合理性，不能证明介入“导致”讨论改善。安排随机分配/平衡顺序的组级对照：无主动主持、语音主持、相同策略的语音+具身反馈；控制任务难度、讨论时长、机器人可见性和策略版本。若交叉设计，处理顺序与学习效应并避免同题重复。

预先选一个主要结果（例如独立盲评创意质量），次要结果包括参与时长/轮次分布、非重复想法数、任务完成质量、决策用时、被打断感、被点名压力和主观自主性。想法数量需独立人工去重，不直接采用本系统字串“发散度”。每组结束后问卷与访谈，保留负面反馈。使用组级/混合效应模型，控制参与者与任务，报告效应量和 CI，多重比较预先控制。

下一窗口的分数上升只能记为“随后变化”，不能当因果收益。未接入真机/传感器时不报告真实硬件成功率。

## 阶段性验收标准（项目提出，需预注册）

1. 进入离线模型评测：所有工程约束通过；输入、配置、模型与输出可追溯；失败和缺失检查点不能隐去。
2. 进入真实小组预试：独立人工测试集冻结后，模型相对规则基线的策略可接受率提升，其会话聚类 95% CI 下界 > 0；误介入率不高于规则基线；无虚构票数、无证据点名和违规动作。证据支持率与输出质量逐维报告，任何严重无据主张需复核。当前合成数据不满足此验收前提。
3. 声称具身系统有效：预注册的组级主要结果显著改善且效应量达到事先定义的实用阈值，同时被打断感/压力未超预定非劣界限。实际阈值与样本量需依据预试而非事后结果决定。
